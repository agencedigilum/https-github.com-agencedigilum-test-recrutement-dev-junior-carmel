# Frontend Web DigiLum

Frontend React Router avec :

- Auth unifiée (email -> connexion/inscription)
- Confirmation email
- Mot de passe oublié / nouveau mot de passe
- Profil
- Dashboard tâches (filtres, recherche, pagination, édition rapide)

## Stack

- Axios (intercepteurs JWT + refresh token)
- React Query
- Framer Motion
- Lucide

## Démarrage

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`  
API attendue: `http://localhost:3000`
